# Paison (パイソン)

Python を元にした、日本語で記述できるプログラミング言語。

## 概要

Paison は、プログラミング初学者や日本語の自然な表現でコードを書きたい人のための日本語プログラミング言語です。
Python の強力なエコシステムをそのまま活かしながら、直感的な日本語の構文で記述できます。

## 開発ロードマップ

- **Phase 1 (現在)**: トランスパイラ方式（Python コードへの事前変換・実行）
  - 日本語キーワードの変換（`しゅつりょく`、`もし`、`ならば` など）
  - 全角記号の正規化（`「」`、`：`、`＝` など）
  - CLI ランナーによる `.pai` スクリプトの実行
- **Phase 2**: 構文解析・AST 変換方式（パーサーによる構文木構築、詳細な日本語構文エラー表示）
- **Phase 3**: 独自評価器・フルスクラッチ（字句解析・構文解析・独自インタプリタ環境）

## Phase 1 構文仕様

### 1. 出力（print）
```paison
しゅつりょく 「Hello World!」
```
Python の `print("Hello World!")` に変換されます。

### 2. 変数と代入
```paison
なまえ ＝ 「QuQuLa89」
ねんれい ＝ 20
```
Python の変数代入に変換されます。全角の `＝` は半角の `=` に正規化されます。

### 3. 条件分岐
```paison
もし ねんれい ＞＝ 20 ならば：
    しゅつりょく 「成人です」
ちがうなら：
    しゅつりょく 「未成年です」
```
Python の `if` / `else` 構文に変換されます。

## 実行方法

```bash
# スクリプトの実行
python -m paison examples/hello.pai
```
