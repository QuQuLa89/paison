# Paison (パイソン)

Paison は、日本語で入力して学べる Python です。

## 概要

Paison は、プログラミング初学者や日本語の自然な表現でコードを書きたい人のための日本語プログラミング言語です。  
Python の記号構造をそのまま維持しているため、Paison で身につけた変数・条件分岐・関数・例外処理の知識を、そのまま Python へ移行できます。外部ライブラリには依存せず、Python 標準機能のみで動作します。

初学者向けの和語構文と、Python 経験者が高速に記述できる英語音読み構文（ひらがな・カタカナ）の双方に対応したハイブリッド設計です。同じファイル内で自由に混在できます。

---

## 主な特徴

- **完全な日本語 IME 対応**: 全角記号（`＝`、`：`、`＋`、`－`、`＊`、`／`、`（）`、`［］`、`“”`）、全角数字（`０〜９`、`．`）、および全角スペースを自動正規化します。IME を切り替えることなく連続して入力できます。
- **Python 準拠の文法構造**: `しゅつりょく（“Hello World!”）` のように「関数名＋括弧＋クォート」の形式を採用しています。独自の特殊記号を排しているため、Python への学習移行が容易です。
- **VS Code 拡張機能を同梱**: シンタックスハイライトと、エディタ右上の「▶」実行ボタンによるワンクリック実行を提供します。

## 構文仕様とコード例

### 1. 文字列・全角記号・全角数字
文字列は半角の `""` / `''`、曲がりクォートの `“”` / `‘’`、三重クォート（`"""` / `'''`）に対応します。  
全角数字（`０〜９`）や全角ピリオド（`．`）による計算も可能です。

```paison
個数 ＝ １２
単価 ＝ ２．５
合計 ＝ 個数 ＊ 単価

しゅつりょく（“計算結果: ” ＋ もじ（合計））
```

### 2. 関数定義と戻り値（def / return）
```paison
かんすう たしざん（あ, い）：
    かえす あ ＋ い

けっか ＝ たしざん（１０, ２０）
しゅつりょく（けっか）
```

音読みスタイルでも同様に記述できます。
```paison
でふ かけざん（あ, い）：
    りたーん あ ＊ い

ぷりんと（かけざん（５, ６））
```

### 3. リストと要素操作
```paison
くだもの ＝ ［“りんご”, “みかん”］
くだもの に “ぶどう” を ついか

しゅつりょく（“登録個数: ” ＋ もじ（ながさ（くだもの）））

名前 を くだもの で くりかえす：
    しゅつりょく（名前）
```

### 4. 例外処理（try / except）
```paison
こころみる：
    数 ＝ かず（“１００”）
    しゅつりょく（“変換成功: ” ＋ もじ（数））
しっぱいしたとき：
    しゅつりょく（“変換に失敗しました”）

とらい：
    ゼロ除算 ＝ １０ ／ ０
えくせぷと：
    ぷりんと（“エラーを検知しました”）
```

### 5. キーボード入力
```paison
名前 ＝ にゅうりょく（“お名前を入力してください: ”）
年齢 ＝ かず（にゅうりょく（“年齢を入力してください: ”））

しゅつりょく（“登録完了: ” ＋ 名前 ＋ “（” ＋ もじ（年齢） ＋ “歳）”）
```

## インストールと実行

### 必須環境
- Python 3.8 以上

### インストール手順
```bash
git clone https://github.com/QuQuLa89/paison.git
cd paison
pip install -e .
```

### コマンドラインからの実行
```bash
# スクリプトファイルの実行
paison examples/hello.pai

# ワンライナー実行
paison -c 'しゅつりょく（“動いた！”）'
```

### VS Code での利用
本リポジトリには VS Code 拡張機能（`extension/`）が同梱されています。
`.pai` ファイルを開くと自動的にシンタックスハイライトが適用され、エディタ右上の「▶」実行ボタンからワンクリックでスクリプトを実行できます。

拡張機能フォルダをローカルに配置する場合:
- Windows: `%USERPROFILE%\.vscode\extensions\paison-vscode` に `extension` フォルダの中身をコピーします。
