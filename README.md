# Paison (パイソン)

Python を元にした、日本語で記述できるプログラミング言語。

## 概要

Paison は、プログラミング初学者や日本語の自然な表現でコードを書きたい人のための日本語プログラミング言語です。
Python の強力なエコシステムをそのまま活かしながら、直感的な日本語の構文で記述できます。外部ライブラリに依存せず、純粋な標準機能のみで動作します。

## 構文仕様

### 1. 文字列と記号の柔軟性
半角の `""` や `()`、`[]` はもちろん、全角の `“”` や `（）`、`［］`、日本語の鍵括弧 `「」` もそのまま利用できます。

```paison
しゅつりょく “Hello World!”
```

### 2. 関数定義と戻り値（def / return）
```paison
かんすう たしざん（あ, い）：
    かえす あ ＋ い

けっか ＝ たしざん（10, 20）
しゅつりょく けっか
```

### 3. リストと配列操作（list / append / len）
```paison
くだもの ＝ ［“りんご”, “みかん”］
くだもの に “ぶどう” を ついか

しゅつりょく “個数: ” ＋ もじ（ながさ（くだもの））

くだもの を 1つずつ で くりかえす：
    しゅつりょく 1つずつ
```

### 4. 例外処理（try / except）
```paison
こころみる：
    しゅつりょく “計算をはじめます”
    けっか ＝ 10 ／ 0
しっぱいしたとき：
    しゅつりょく “ゼロで割ることはできませんでした”
```

### 5. キーボード入力と日本語組み込み関数
```paison
なまえ ＝ にゅうりょく（“お名前は？: ”）
ねんれい ＝ かず（にゅうりょく（“年齢は？: ”））

しゅつりょく “こんにちは、” ＋ なまえ ＋ “（” ＋ もじ（ねんれい） ＋ “歳）”
```

- `かず（...）`: 整数変換（`int`）
- `もじ（...）`: 文字列変換（`str`）
- `ながさ（...）`: 長さ・要素数（`len`）
- `はいれつ（...）`: リスト変換（`list`）
- `にゅうりょく（...）`: キーボード入力（`input`）
- `しゅつりょく（...）`: 出力（`print`）

## 実行方法

```bash
# スクリプトの実行
paison examples/quotes_sample.pai

# ワンライナー実行
paison -c "しゅつりょく “動いた！”"
```
