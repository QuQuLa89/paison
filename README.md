# Paison (パイソン)

Paison は、日本語で入力して学べるPythonです。

## 概要

Paison は、プログラミング初学者や日本語の自然な表現でコードを書きたい人のための日本語プログラミング言語です。
Python の強力なエコシステムをそのまま活かしながら、直感的な日本語の構文で記述できます。外部ライブラリに依存せず、純粋な標準機能のみで動作します。

## 構文仕様

### 1. 文字列と記号の柔軟性
文字列には半角の `"..."`、`'...'`、三重クォート（`"""..."""`、`'''...'''`）、曲がったクォートの `“...”`、`‘...’` を利用できます。
括弧は半角の `()`、`[]` と全角の `（）`、`［］` に対応しています。出力も Python の `print(...)` と同じ関数呼び出し形式で記述します。

```paison
しゅつりょく（“Hello World!”）
```

### 2. 関数定義と戻り値（def / return）
```paison
かんすう たしざん（あ, い）：
    かえす あ ＋ い

けっか ＝ たしざん（10, 20）
しゅつりょく（けっか）
```

### 3. リストと配列操作（list / append / len）
```paison
くだもの ＝ ［“りんご”, “みかん”］
くだもの に “ぶどう” を ついか

しゅつりょく（“個数: ” ＋ もじ（ながさ（くだもの）））

くだもの名 を くだもの で くりかえす：
    しゅつりょく（くだもの名）
```

### 4. 例外処理（try / except）
```paison
こころみる：
    しゅつりょく（“計算をはじめます”）
    けっか ＝ 10 ／ 0
しっぱいしたとき：
    しゅつりょく（“ゼロで割ることはできませんでした”）
```

### 5. キーボード入力と日本語組み込み関数
```paison
なまえ ＝ にゅうりょく（“お名前は？: ”）
ねんれい ＝ かず（にゅうりょく（“年齢は？: ”））

しゅつりょく（“こんにちは、” ＋ なまえ ＋ “（” ＋ もじ（ねんれい） ＋ “歳）”）
```

- `かず（...）`: 整数変換（`int`）
- `もじ（...）`: 文字列変換（`str`）
- `ながさ（...）`: 長さ・要素数（`len`）
- `はいれつ（...）`: リスト変換（`list`）
- `にゅうりょく（...）`: キーボード入力（`input`）
- `しゅつりょく（...）`: 出力（`print`）

## 実行方法

```bash
# スクリプトの実行
paison examples/hello.pai

# ワンライナー実行
paison -c 'しゅつりょく（"動いた！"）'
```
